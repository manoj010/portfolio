# AI Slop Is A Trust Problem

AI slop is becoming one of those phrases people use before they fully agree on what it means.

Sometimes it means AI-generated text.

Sometimes it means generic posts.

Sometimes it means engagement bait.

Sometimes it means synthetic images, fake replies, low-effort videos, fake expertise, or recycled advice dressed up with confident formatting.

But the useful definition is narrower:

```txt
AI slop is low-value generated content that pollutes attention.
```

The key word is not "AI."

The key word is "low-value."

## The Fresh Signal

LinkedIn recently started testing a feedback button for posts that users think are AI slop. According to [The Verge](https://www.theverge.com/news/761747/linkedin-ai-slop-button-testing), the button has already been clicked more than one million times.

That number matters less as a precise measurement of AI content and more as a trust signal.

People are not only saying:

```txt
this might have used AI
```

They are saying:

```txt
this does not feel worth my attention
```

That is a different problem.

And it is the problem platforms actually have to solve.

## AI Use Is Not The Same As Slop

Using AI does not automatically make a post bad.

A person can use AI to:

- clean up rough notes
- translate an idea
- structure an argument
- summarize research
- improve accessibility
- brainstorm examples
- check grammar
- prepare a first draft

That can still produce useful human communication if the final post contains judgment, context, evidence, experience, or a real point of view.

The problem is when AI is used to remove effort instead of clarify thought.

There is a big difference between:

```txt
AI-assisted writing
```

and:

```txt
AI-generated nothingness
```

Platforms need to learn that difference.

## Why Slop Spreads

AI slop spreads because it is cheap.

Before generative AI, producing a polished-looking post required at least some time.

Now a person can generate:

- ten leadership posts
- twenty motivational threads
- fifty comments
- a hundred generic summaries
- endless "hot takes" with no heat

The cost of producing plausible content collapsed.

But the cost of reading did not.

Every weak post still consumes someone else's attention.

That is the hidden tax:

```txt
cheap production
expensive consumption
```

When production becomes nearly free, ranking becomes more important.

## This Is A Ranking Problem

Platforms often treat content quality as a moderation problem.

Some things are allowed.

Some things are banned.

AI slop sits in the middle.

It is usually not illegal.

It is often not abusive.

It may not violate any explicit policy.

It is just bad.

So the answer is not simply:

```txt
remove all AI content
```

The answer is closer to:

```txt
rank low-value content lower
rank authentic, useful, specific content higher
```

That is a product design problem.

Not just a moderation problem.

## What The Button Really Measures

A "seems like AI slop" button does not perfectly detect AI.

Users can be wrong.

People may dislike a post for unrelated reasons.

Some human writing is generic enough to look AI-generated.

Some AI-assisted writing is useful enough to feel human.

So the button should not be treated as a truth machine.

It should be treated as a signal.

Like:

- not helpful
- low quality
- repetitive
- generic
- untrustworthy
- engagement bait

That signal can help platforms learn what users are tired of.

I wrote about a related issue in [AI Watermarks Are Not Truth Machines](/blog/ai-watermarks-not-truth-machines). Detection is never the whole answer. Systems need context, incentives, and human judgment.

The same applies here.

## The Three Buckets

The useful split is not:

```txt
human vs AI
```

It is:

```txt
human insight
AI-assisted but useful
low-value slop
```

### Human Insight

This is content with lived experience, original analysis, specific examples, useful disagreement, careful research, or a perspective that could not be copied from a prompt template.

It may be imperfect.

That is fine.

Imperfection is often part of the signal.

### AI-Assisted But Useful

This is content where AI helped shape, translate, summarize, or polish something real.

It still has a point.

It still adds value.

It still belongs to a person.

### Low-Value Slop

This is content that exists mainly because it was easy to generate.

It may be polished.

It may be formatted well.

It may even sound confident.

But it does not repay attention.

That is what platforms should downrank.

## Authenticity Is A Distribution Signal

Authenticity used to be treated as a brand quality.

Now it is becoming an infrastructure requirement.

Feeds need to know:

- Did this come from a real person?
- Does it add something specific?
- Is it repetitive?
- Is it engagement bait?
- Is it copied from common templates?
- Do users hide it quickly?
- Do users report it as low value?
- Do credible people engage meaningfully?
- Does it cite sources when making claims?

This is not about punishing people for using tools.

It is about protecting the feed from becoming a fog machine.

If every post sounds professional but says nothing, the platform loses trust.

## The Professional Network Problem

AI slop feels especially strange on professional networks.

People go there for:

- hiring
- industry updates
- technical lessons
- career moves
- company news
- thoughtful opinions
- real work experience

When the feed fills with generic AI posts, the value proposition gets weaker.

The user starts asking:

```txt
Is this a real person saying something useful?
Or is this a template chasing engagement?
```

Once that doubt becomes normal, every post has to work harder to feel real.

That is a platform trust problem.

## Creators Also Need Better Standards

This is not only on platforms.

People posting with AI should raise their own bar.

Before publishing, ask:

- Did I add a real example?
- Did I include something I actually know?
- Did I remove generic phrases?
- Did I cite the source of claims?
- Did I say something falsifiable?
- Would I still post this if my name were not attached?
- Could a hundred other people post the same thing?

That last question is brutal but useful.

If a hundred people could post the same thing, it is probably not your insight yet.

## What Platforms Should Do

A useful anti-slop system should not rely on one detector.

It should combine:

- user feedback
- duplicate detection
- engagement quality
- source reputation
- dwell time
- hide/report behavior
- originality signals
- link and citation quality
- account behavior
- topic repetition

And it should avoid one lazy mistake:

```txt
AI-generated = bad
human-written = good
```

That is false.

Plenty of human content is slop.

Plenty of AI-assisted content is useful.

The ranking system should care about value.

## The Link To Dead Internet Theory

This connects directly to [Dead Internet Theory](/blog/dead-internet-theory), but from a narrower angle.

Dead Internet Theory is about the web feeling less human because of bots, automation, synthetic engagement, and generated content.

AI slop is one mechanism that creates that feeling.

It fills the feed without deepening the conversation.

It makes the internet move without making it feel alive.

That is why the response has to be more than labeling.

The goal is not to prove which posts touched a model.

The goal is to keep human signal discoverable.

## The Takeaway

AI slop is not mainly a writing problem.

It is a trust problem.

It happens when cheap generated content floods feeds faster than ranking systems can protect attention.

The answer is not to ban every AI-assisted post.

The answer is to reward what is specific, useful, sourced, accountable, and human-owned.

```txt
AI assistance is fine.
Attention pollution is not.
```

Authenticity is becoming a distribution signal.
